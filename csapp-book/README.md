# CS:APP Companion Materials (official, free)

Official free resources from https://csapp.cs.cmu.edu/3e/ (Student Site).
The full textbook itself is a paid Pearson book — NOT redistributed here.

## Files

| File/Dir | What it is |
|---|---|
| `preface3e.pdf` | Table of contents + preface of CS:APP 3e (417KB). Good for chapter overview. |
| `code/` | All C source code examples from the book, organized by chapter (extracted from code-all.tar). Run these while reading chapters. |
| `code.tar` | Compact archive of the same code/ examples (235KB). |
| `code-all.tar` | Full archive: sources + headers + Makefiles used to produce the manuscript (28MB). Already extracted into `code/`. |

## Usage

-   Lab handouts live in sibling dirs (`~/P/labs/<lab>/`); per-lab tasks in zk.
-   This dir is reference material for Pre-reading — not a lab handout.
